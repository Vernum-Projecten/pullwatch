:::note[Binnenkort]
Aan dit deel van Pullwatch wordt nog gewerkt. Deze pagina legt het volledig uit zodra het er is.
:::

Pullwatch krijgt een lokale [Model Context Protocol](https://modelcontextprotocol.io)-server, zodat een coding agent op je Mac kan vragen wat Pullwatch weet: je gevolgde pull requests en hun checks, tags, hoe elke repository ervoor staat, de verouderde packages en de bekende kwetsbaarheden. De agent leest alleen, ziet alleen de repositories die je volgt en krijgt nooit een token.

Een agent een taak geven kan nu al: **Kopieer voor een AI-agent** op de pagina van een repository zet een kopje van die pagina als opdracht in Markdown op het klembord (zie [Repositories](/nl/using/repositories/#kopieer-voor-een-ai-agent)).

Volg de voortgang in [issue #139](https://github.com/Vernum-Projecten/pullwatch/issues/139).
