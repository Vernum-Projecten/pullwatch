---
title: Tastenkürzel
description: Jedes Tastenkürzel in der Menüleiste der Fenster von Pullwatch und im Menü in der Menüleiste.
---

Die Menüleiste folgt der Reihenfolge von Apple: Pullwatch, Ablage, Bearbeiten, Darstellung, Gehe zu, Objekt, Repository, Fenster und Hilfe. Jeder Befehl ist immer da; einer, der nicht zur Auswahl passt, ist abgeblendet.

## Pullwatch

| Kürzel | Was es tut |
|---|---|
| | Nach Updates suchen … |
| ⌘, | Einstellungen |
| ⌘H | Pullwatch ausblenden |
| ⌘Q | Pullwatch beenden |

## Ablage

| Kürzel | Was es tut |
|---|---|
| ⌘N | Neues Konto …: Einstellungen, Konten, mit der Wahl des Dienstes |
| ⇧⌘N | Einem Repository folgen… |
| ⌘O | Die Auswahl (oder das offene Repository) im Browser öffnen; bei einem Paket seine Seite in der Registry |
| ⌘W | Das Fenster schließen |

## Bearbeiten

| Kürzel | Was es tut |
|---|---|
| ⌘F | Suchen …: im aktuellen Bereich suchen |

## Darstellung

| Kürzel | Was es tut |
|---|---|
| ⌃⌘S | Die Seitenleiste ein- oder ausblenden |
| ⌥⌘T | Die Symbolleiste ein- oder ausblenden |
| ⌘R | Neu laden: das offene Repository, sonst alles abrufen oder prüfen |
| ⌃⌘F | Vollbild ein- oder ausschalten |

## Gehe zu

| Kürzel | Was es tut |
|---|---|
| ⌘[ | Zurück von der Seite eines Repositorys |
| ⌘1 | PRs |
| ⌘2 | Tags und Releases |
| ⌘3 | Branches |
| ⌘4 | Statistiken |
| ⌘5 | Repositories |
| ⌘6 | Abhängigkeiten |
| ⌘7 | Pakete |
| ⌘↓ | Repository-Seite: die Seite des ausgewählten Repositorys |

## Objekt

Der ausgewählte Pull Request, Tag oder das ausgewählte Release.

| Kürzel | Was es tut |
|---|---|
| ⇧⌘U | Als gelesen markieren oder Als ungelesen markieren |
| ⌘K | Alle als gelesen markieren |
| ⇧⌘L | Link kopieren |
| ⌥⇧⌘L | Verweis kopieren: der ausgewählten Pull Requests, etwa `FerroHEALTH/FerroFED#1570` |

## Repository

Das ausgewählte Repository oder die offene Seite eines Repositorys.

| Kürzel | Was es tut |
|---|---|
| | Repository prüfen: das Repository erneut prüfen |
| ⌥⌘R | Alle Repositorys prüfen |
| ⌥⌘S | Repository-Statistiken |
| ⇧⌘C | Abhängigkeiten für Agent kopieren |
| ⇧⌘R | Verlauf erneut abrufen |
| ⌘. | Abrufen stoppen |
| ⌥⌘I | Den Inspektor auf der Seite eines Repositorys ein- oder ausblenden (Symbolleiste) |

## Fenster und Hilfe

| Kürzel | Was es tut |
|---|---|
| ⌘M | Im Dock ablegen |
| ⌘0 | Pullwatch: das Hauptfenster öffnen oder nach vorne holen |

Hilfe führt zu dieser Dokumentation (Pullwatch-Hilfe), zu dieser Seite (Tastaturkurzbefehle), zu den Versionshinweisen deiner Version (Neu in Pullwatch), zu Datenschutz und Quellen (Einstellungen, Quellen: jede Verbindung, die Pullwatch aufbaut), zu einem neuen Issue auf GitHub (Problem melden …) und zu den Danksagungen.

## Dock

Solange das Symbol im Dock zu sehen ist, bietet sein Menü **Neu laden** und **Alle Repositorys prüfen**.

## Menü in der Menüleiste

| Kürzel | Was es tut |
|---|---|
| ⌘R | Jetzt aktualisieren |
| ⌘, | Einstellungen |
| ⌘K | Alle gelesen |
| ⌘O | Das Hauptfenster öffnen |
| ⌘Q | Pullwatch beenden |

## Sprünge

Die Seite eines Repositorys verlinkt auf alle seine Pull Requests und Tags, auf seine Statistiken und von einer Schwachstelle aus auf dieses Paket in Abhängigkeiten. In Statistiken verlinkt ein ausgewählter Autor auf seine Pull Requests und ein Repository auf seine Seite. Im Menü in der Menüleiste öffnest du per Rechtsklick auf einen Pull Request oder Tag sein Repository.
