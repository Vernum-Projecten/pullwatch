## Hauptfenster: das Menü Gehe zu

| Kürzel | Was es tut |
|---|---|
| ⌘1 | PRs |
| ⌘2 | Tags und Releases |
| ⌘3 | Statistiken |
| ⌘4 | Repositories |
| ⌘5 | Abhängigkeiten |
| ⌘F | Den aktuellen Bereich durchsuchen |
| ⌘R | Aktualisieren: das offene Repository, sonst alles abfragen oder prüfen |
| ⌘[ | Zurück von der Seite eines Repositorys |
| ⌘O | Die Auswahl (oder das offene Repository) im Browser öffnen |
| ⇧⌘U | Die Auswahl als gelesen oder ungelesen markieren |
| ⌘K | Alle als gelesen markieren |
| ⌘↓ | Die Seite des ausgewählten Repositorys öffnen |
| ⌥⌘S | Statistik des Repositorys |
| ⇧⌘C | Abhängigkeiten des Repositorys kopieren |
| ⇧⌘N | Einem Repository folgen |
| ⇧⌘R | Verlauf erneut abrufen |
| ⌥⌘R | Alle Repositorys prüfen |
| ⌘. | Abrufen stoppen |
| ⌥⌘I | Den Inspektor auf der Seite eines Repositorys ein- oder ausblenden |
| ⌘, | Einstellungen |

## Menü

| Kürzel | Was es tut |
|---|---|
| ⌘R | Jetzt aktualisieren |
| ⌘, | Einstellungen |
| ⌘K | Alle gelesen |
| ⌘O | Das Hauptfenster öffnen |
| ⌘Q | Pullwatch beenden |

## Sprünge

Die Seite eines Repositorys verlinkt auf alle seine Pull Requests und Tags, auf seine Statistiken und von einer Schwachstelle aus auf dieses Paket in Abhängigkeiten. In Statistiken verlinkt ein ausgewählter Autor auf seine Pull Requests und ein Repository auf seine Seite. Im Menü öffnest du per Rechtsklick auf einen Pull Request oder Tag sein Repository.
