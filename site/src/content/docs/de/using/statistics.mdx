**Statistiken** in der Seitenleiste zeigt die Aktivität bei Pull Requests aus dem Verlauf, den Pullwatch führt.

<Screenshot name="stats" alt="Der Bereich Statistiken: 8 geöffnete Pull Requests, 2 offene Entwürfe, 1 ohne Merge geschlossen, eine mediane Durchlaufzeit von 12 Stunden und 6 aktive Autoren, ein Balkendiagramm pro Monat und Ranglisten von Autoren und Repositories." />

- Geöffnete und gemergte Pull Requests pro Woche, Monat oder Jahr (die letzten 12 Wochen, 12 Monate oder 5 Jahre).
- Die im aktuellen Zeitraum geöffneten und gemergten Pull Requests, offene Entwürfe, die mediane Zeit vom Öffnen bis zum Merge und die Anzahl aktiver Autoren.
- Ranglisten der Autoren und der aktivsten Repositories.

Filtere auf ein Projekt oder einen Autor; klicke auf einen Namen in der Rangliste, um ihn auszuwählen, und springe von dort zu den Pull Requests dieses Autors oder zur Seite des Repositorys. Bots (`[bot]` im Namen) sind standardmäßig ausgeblendet. **Co-Autoren mitzählen** im Menü der Autoren zählt einen Pull Request auch für jeden seiner Co-Autoren.

Die Seite eines Repositorys hat dasselbe Diagramm pro Monat für dieses Repository allein.

Statistiken zählen Pull Requests, keine Commits, und reichen so weit zurück wie der Verlauf (Einstellungen, Allgemein, **Verlauf behalten**).
