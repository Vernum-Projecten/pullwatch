**Branches** in der Seitenleiste (⌘3) zeigt Pushes auf die Branches der Repositories, denen du folgst, neueste zuerst. Der Bereich beantwortet eine Frage, die die Listen PRs und Tags nicht beantworten: Wer arbeitet woran, bevor es einen Pull Request oder Tag gibt.

<Screenshot name="branches" alt="Der Bereich Branches: Pushes auf Branches von drei Repositories, jeweils mit Branch-Namen, Repository, Autor, der Zahl neuer Commits und dem Zeitpunkt des Pushs." />

## Was eine Zeile zeigt

Jede Zeile hat den Branch, das Repository, wer gepusht hat (mit Bild), die Commits und wann. Die Spalte Commits sagt, was passiert ist:

- `+3`: drei neue Commits, seit Pullwatch zuletzt nachgesehen hat.
- **Force-Push**: Der Branch wurde umgeschrieben, sein Verlauf knüpft also nicht mehr an den früheren an.
- **Neuer Branch**: Den Branch gab es noch nicht.
- Ohne Label: der letzte Commit eines Branches, der sich in den letzten 14 Tagen bewegt hat. So füllt Pullwatch die Liste beim ersten Lesen eines Repositorys, damit der Bereich nicht leer beginnt.

Pullwatch sieht, was sich zwischen zwei Lesevorgängen geändert hat, nicht jeden einzelnen Push. Drei Pushes zwischen zwei Lesevorgängen sind eine Zeile mit allen neuen Commits.

## Suchen und Filter

Suche nach Branch, Repository oder Person. Die Symbolleiste filtert nach einem Repository oder einer Person, und ein Klick auf einen Namen in der Tabelle filtert ebenfalls nach dieser Person. **Nur andere** blendet deine eigenen Pushes aus.

Pullwatch erkennt deine eigenen Pushes an deinem Konto auf GitHub, und auf Bitbucket und Gitea dort, wo das Konto mit der Person verknüpft ist. Sonst vergleicht es Namen und E-Mail-Adresse des Autors mit deinen.

Doppelklicke eine Zeile (oder wähle **Im Browser öffnen** im Kontextmenü), um den Vergleich beim Dienst zu öffnen. Pullwatch zeigt selbst keine Commits oder Dateien.

## Keine Mitteilungen

Pushes lösen nie eine Mitteilung aus, zählen nicht als ungelesen und erscheinen weder im Menüfenster noch im Dock-Badge. Das ist eine Liste zum Nachsehen, kein Strom, dem man folgen muss.

## Branches folgen

Branches folgen zusammen mit den Pull Requests, pro Repository. Um sie für ein Repository auszuschalten, entferne den Haken bei **Branches** in der Repository-Liste des Kontos (Einstellungen, Konten). Folgt kein Repository Branches, bietet der Bereich **Branches folgen** an.

Branches werden höchstens alle 15 Minuten gelesen, getrennt von Pull Requests und Tags. Ein Rate Limit bei Branches hält Pull Requests oder Tags nie auf: Sie kommen wie gewohnt an, und Branches warten, bis das Limit vorbei ist. Pushes bleiben so lange erhalten wie der Verlauf (Einstellungen, Allgemein, **Verlauf behalten**).
