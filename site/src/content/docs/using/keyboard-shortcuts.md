---
title: Keyboard shortcuts
description: Every shortcut in the menu bar of the Pullwatch windows and in the menu panel.
---

The menu bar follows Apple's order: Pullwatch, File, Edit, View, Go, Item, Repository, Window and Help. Every command is always there; one that does not apply to what is selected is dimmed.

## Pullwatch

| Shortcut | What it does |
|---|---|
| | Check for Updates… |
| ⌘, | Settings |
| ⌘H | Hide Pullwatch |
| ⌘Q | Quit Pullwatch |

## File

| Shortcut | What it does |
|---|---|
| ⌘N | New Account…: Settings, Accounts, with the choice of service |
| ⇧⌘N | Watch a Repository… |
| ⌘O | Open the selection (or the open repository) in the browser; for a package, its page in the registry |
| ⌘W | Close the window |

## Edit

| Shortcut | What it does |
|---|---|
| ⌘F | Find: search the current section |

## View

| Shortcut | What it does |
|---|---|
| ⌃⌘S | Show or hide the sidebar |
| ⌥⌘T | Show or hide the toolbar |
| ⌘R | Reload: the open repository, otherwise poll or check everything |
| ⌃⌘F | Enter or exit full screen |

## Go

| Shortcut | What it does |
|---|---|
| ⌘[ | Back from a repository page |
| ⌘1 | PRs |
| ⌘2 | Tags and Releases |
| ⌘3 | Branches |
| ⌘4 | Statistics |
| ⌘5 | Repositories |
| ⌘6 | Dependencies |
| ⌘7 | Packages |
| ⌘↓ | The selected repository's page |

## Item

The selected pull request, tag or release.

| Shortcut | What it does |
|---|---|
| ⇧⌘U | Mark as read or unread |
| ⌘K | Mark all as read |
| ⇧⌘L | Copy the link |
| ⌥⇧⌘L | Copy the reference of the selected pull requests, such as `FerroHEALTH/FerroFED#1570` |

## Repository

The selected repository, or the open repository page.

| Shortcut | What it does |
|---|---|
| | Check the repository again |
| ⌥⌘R | Check all repositories |
| ⌥⌘S | Repository statistics |
| ⇧⌘C | Copy the repository's dependencies for an agent |
| ⇧⌘R | Fetch the history again |
| ⌘. | Stop fetching |
| ⌥⌘I | Show or hide the inspector on a repository page (toolbar) |

## Window and Help

| Shortcut | What it does |
|---|---|
| ⌘M | Minimize |
| ⌘0 | Pullwatch: open the main window or bring it to the front |

Help leads to this documentation, this page, the release notes of your version, Privacy and Sources (Settings, Sources: every connection Pullwatch makes), a new issue on GitHub, and the acknowledgements.

## Dock

While the Dock icon shows, its menu offers **Reload** and **Check All Repositories**.

## Menu panel

| Shortcut | What it does |
|---|---|
| ⌘R | Refresh now |
| ⌘, | Settings |
| ⌘K | Mark all read |
| ⌘O | Open the main window |
| ⌘Q | Quit Pullwatch |

## Jumps

A repository page links to all its pull requests and tags, to its statistics, and from a vulnerability to that package in Dependencies. In Statistics a selected author links to their pull requests and a repository to its page. In the menu panel, right-click a pull request or tag to open its repository.
