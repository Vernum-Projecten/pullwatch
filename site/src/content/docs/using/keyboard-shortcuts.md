## Main window: the Go menu

| Shortcut | What it does |
|---|---|
| ⌘1 | PRs |
| ⌘2 | Tags and Releases |
| ⌘3 | Statistics |
| ⌘4 | Repositories |
| ⌘5 | Dependencies |
| ⌘F | Search the current section |
| ⌘R | Refresh: the open repository, otherwise poll or check everything |
| ⌘[ | Back from a repository page |
| ⌘O | Open the selection (or the open repository) in the browser |
| ⇧⌘U | Mark the selection as read or unread |
| ⌘K | Mark all as read |
| ⌘↓ | Open the selected repository's page |
| ⌥⌘S | Repository statistics |
| ⇧⌘C | Copy the repository's dependencies |
| ⇧⌘N | Watch a repository |
| ⇧⌘R | Fetch the history again |
| ⌥⌘R | Check all repositories |
| ⌘. | Stop fetching |
| ⌥⌘I | Show or hide the inspector on a repository page |
| ⌘, | Settings |

## Menu panel

| Shortcut | What it does |
|---|---|
| ⌘R | Refresh now |
| ⌘, | Settings |
| ⌘K | Mark all read |
| ⌘O | Open the main window |
| ⌘Q | Quit Pullwatch |

## Jumps

A repository page links to all its pull requests and tags, to its statistics, and from a vulnerability to that package in Dependencies. In Statistics a selected author links to their pull requests and a repository to its page. In the menu panel, right-click a pull request or tag to open its repository.
