:::note[Coming soon]
This part of Pullwatch is still being built. This page explains it in full once it ships.
:::

Pullwatch is getting a local [Model Context Protocol](https://modelcontextprotocol.io) server, so a coding agent on your Mac can ask it what it knows: your followed pull requests and their checks, tags, the state of each repository, its outdated packages and its known vulnerabilities. The agent only reads, it sees only the repositories you follow, and it never gets a token.

You can already hand an agent a task today: **Copy for an AI Agent** on a repository page puts a section of that page on the clipboard as a Markdown brief (see [Repositories](/using/repositories/#copy-for-an-ai-agent)).

Follow the progress in [issue #139](https://github.com/Vernum-Projecten/pullwatch/issues/139).
