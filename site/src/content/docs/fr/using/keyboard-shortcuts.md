## Fenêtre principale : le menu Aller

| Raccourci | Action |
|---|---|
| ⌘1 | PR |
| ⌘2 | Tags et versions publiées |
| ⌘3 | Statistiques |
| ⌘4 | Dépôts |
| ⌘5 | Dépendances |
| ⌘F | Rechercher dans la section actuelle |
| ⌘R | Actualiser : le dépôt ouvert, sinon interroger ou vérifier tout |
| ⌘[ | Revenir d’une page de dépôt |
| ⌘O | Ouvrir la sélection (ou le dépôt ouvert) dans le navigateur |
| ⇧⌘U | Marquer la sélection comme lue ou non lue |
| ⌘K | Tout marquer comme lu |
| ⌘↓ | Ouvrir la page du dépôt sélectionné |
| ⌥⌘S | Statistiques du dépôt |
| ⇧⌘C | Copier les dépendances du dépôt |
| ⇧⌘N | Suivre un dépôt |
| ⇧⌘R | Récupérer à nouveau l’historique |
| ⌥⌘R | Vérifier tous les dépôts |
| ⌘. | Arrêter la récupération |
| ⌥⌘I | Afficher ou masquer l’inspecteur sur une page de dépôt |
| ⌘, | Réglages |

## Panneau du menu

| Raccourci | Action |
|---|---|
| ⌘R | Actualiser maintenant |
| ⌘, | Réglages |
| ⌘K | Tout lu |
| ⌘O | Ouvrir la fenêtre principale |
| ⌘Q | Quitter Pullwatch |

## Navigation

Une page de dépôt renvoie vers toutes ses pull requests et tous ses tags, vers ses statistiques, et depuis une vulnérabilité vers ce paquet dans Dépendances. Dans Statistiques, un auteur sélectionné renvoie vers ses pull requests et un dépôt vers sa page. Dans le panneau du menu, cliquez avec le bouton droit sur une pull request ou un tag pour ouvrir son dépôt.
