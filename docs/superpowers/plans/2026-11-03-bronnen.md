# Bronnen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Een tabblad Bronnen in Instellingen dat elke externe verbinding van Pullwatch toont, databronnen laat uitzetten, overal "Niet gecontroleerd: bron xxx staat uit" toont waar daardoor niets gecontroleerd is, en het overzicht naar het klembord kopieert. Plus: vensters die vanuit het menu openen komen weer bovenaan.

**Architecture:** Eén catalogus van bronnen (`DataSourceID` + `DataSource`) in `PullwatchCore`. `AppConfig.disabledSources` bewaart wat uit staat. `VersionChecker` slaat aanroepen van uitgezette bronnen over en legt per repo vast welke bronnen overgeslagen zijn (`RepoVersions.skippedSources`). `VersionReport.visible(disabled:)` verbergt eerder opgehaalde gegevens van uitgezette bronnen. De app geeft de set door, toont de teksten en het nieuwe tabblad.

**Tech Stack:** Swift 6.4, SwiftUI (macOS 26.6+), Swift Testing, `MockHTTPClient` uit `PullwatchTestSupport`, String Catalogs (nl, en, de, fr).

**Spec:** `docs/superpowers/specs/2026-11-03-bronnen-design.md`

## Global Constraints

- macOS 26.6 en later; Swift zoals `.claude/rules/swift.md` zegt. Commentaar en dit soort documenten in het Nederlands; commit-onderwerpen in het Engels (Conventional Commits).
- Geen "·"-scheidingstekens of em dashes in tekst voor de gebruiker.
- Vaste formules: "Niet gecontroleerd: bron %@ staat uit", "Versie niet gecontroleerd: bron %@ staat uit", "Details niet opgehaald: bron %@ staat uit".
- Een uitgezette bron geeft nergens "Geen kwetsbaarheden", "Actueel" of "geen meldingen".
- Standaard staat alles aan; een `config.json` zonder `disabledSources` betekent alles aan; een onbekende id in `disabledSources` wordt genegeerd, niet als fout behandeld.
- Na elke tekstwijziging: `bash scripts/dev/sync-strings.sh`, daarna Engels, Duits en Frans invullen in elke geraakte `Localizable.xcstrings` (`LocalizationTests` faalt anders).
- Tests: `swift test --package-path PullwatchKit` en `xcodebuild test -project Pullwatch/Pullwatch.xcodeproj -scheme Pullwatch -destination 'platform=macOS' -skip-testing:PullwatchUITests`. Nooit een test verzwakken of overslaan.
- Een changelog-fragment in `changelog.d/` volgens `changelog.d/README.md` (de CI-guard eist er een).

## Review Focus

1. **OSV weer aan na een periode uit:** geen stortvloed aan meldingen over "nieuwe" kwetsbaarheden. Test `osvBackOnDoesNotNotify` in Task 3.
2. **Een registry uit terwijl `versions.json` nog oude nieuwste-versies van dat ecosysteem heeft:** die packages tonen niet "Actueel" maar "Versie niet gecontroleerd". Test `visibleHidesLatestOfDisabledRegistry` in Task 5.
3. **Een herhaalde check van één repo (`run(account:repo:)`) of `runMissing`:** respecteert de uitgezette bronnen net als de dagelijkse check. Test `singleRepoRunSkipsDisabled` in Task 3.
4. **Een repo zonder packages met OSV uit:** geen "Niet gecontroleerd"-tekst (er viel niets te controleren), zoals `vulnerabilityError` nu ook alleen bij packages gezet wordt. Test `osvOffWithoutDependenciesSkipsNothing` in Task 3.
5. **Een GitHub Enterprise-account met GitHub-beveiliging uit:** ook daar geen `securityAlerts`-aanroep. Test `gitHubSecurityOffCoversEnterprise` in Task 3.
