Sinds de opruiming van #112 staan de bronnen per module en gebied (`PullwatchKit/Sources/<Module>/<Gebied>/`) en zijn de grote bestanden per onderdeel gesplitst, en sinds #149 heeft de app een map per onderdeel (`Pullwatch/Pullwatch/<Onderdeel>/`, model en views samen); `CLAUDE.md` geeft de huidige indeling. > **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Onderdeel Repo's (lijst per project + pagina per repo) in plaats van Repo-controle, plus momentopnames van elke versiecheck.

**Architecture:** Core rekent `RepoSummary`'s uit config, `VersionReport` en `History`; de App toont ze. Momentopnames via `JSONFileStore`.

**Spec:** `docs/superpowers/specs/2026-11-01-repos-design.md`

## Global Constraints

- Oude `config.json`/`versions.json` blijven laden; nieuwe UI-strings in NL/EN/DE/FR.
- `swift test` groen na Core-taken, app-build groen na App-taken.

## Review Focus

1. Repo die gevolgd wordt maar nog niet gecheckt is → staat in de lijst, grijs.
2. Accountfout-regel in het rapport (repo zonder "/") → niet als repo tonen.
3. Hoofdletterverschil tussen repoWatch-key en providernaam → één regel.
4. Meer dan 730 momentopnames → oudste vallen eraf.

### Task 1: RepoOverview (Core)

**Files:** Create `Sources/PullwatchCore/RepoOverview.swift`; Modify `Models.swift` (`Account.repoWebURL`); Test `Tests/PullwatchCoreTests/RepoOverviewTests.swift`.

**Interfaces (Produces):**
- `Account.repoWebURL(_ repo: String) -> URL?`: Azure `https://dev.azure.com/<org>/<project>/_git/<repo>`, GitHub `https://github.com/<owner>/<repo>`.
- `enum RepoHealth { problem, behind, ok, unknown }`.
- `struct RepoSummary: Identifiable, Hashable { id: String /* "<accountId>/<repo>" = RepoVersions.id */; accountId: UUID; repo: String; group: HistoryGroup.ID; versions: RepoVersions?; openPullRequests: Int; latestTag: String?; packageUpdates: [PackageSummary]; health: RepoHealth }`.
- `RepoOverview.summaries(accounts: [Account], report: VersionReport?, history: History) -> [RepoSummary]`: slechtste eerst (problem, behind, unknown, ok), dan naam.
- `RepoOverview.groups(_ summaries: [RepoSummary], accountNames: [UUID: String]) -> [HistoryGroup]`: `unreadCount` = aantal `.problem`.

- [ ] Tests voor Review Focus 1–3, health-regels, open PR-telling, URL's. RED → implementeer → GREEN → commit.
